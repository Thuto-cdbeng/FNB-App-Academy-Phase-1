## About

This repository contains solutions and practice files for a self‑paced Python course separated into six units. The exercises progress from basic syntax to small, practical programs so you can practice real problem solving in Python.

Audience: beginners or anyone refreshing Python fundamentals.

## Course Overview

This self‑paced course consists of six units designed to introduce the fundamental concepts of Python programming, from writing your first lines of code to building small applications.

Each unit builds on the previous one and typically covers:

- **Unit 1:** Introduction to Python basics (variables, input/output, simple logic)
- **Unit 2:** String manipulation and formatting
- **Unit 3:** Numbers, arithmetic, and simple calculators
- **Unit 4:** Lists, dictionaries, and basic data structures
- **Unit 5:** Conditional logic and program flow
- **Unit 6:** Loops, repetition, and small project assembly

By the end of the course you should be comfortable writing basic Python scripts and combining fundamentals into small programs.

## Quick Start — Run a file

1. Clone the repo:

```bash
git clone https://github.com/Thuto-cdbeng/FNB-App-Academy-Phase-1.git
cd FNB-App-Academy-Phase-1
```

2. (Optional but recommended) Create and activate a virtual environment:

```bash
python3 -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows (PowerShell)
.\.venv\Scripts\Activate.ps1
```

3. Run a script:

```bash
python Unit-1/digital_ticket_counter.py
```

Notes:
- Use Python 3.x. If your system uses both Python 2 and 3, prefer `python3` where needed.
- If a script expects user input, follow on-screen prompts.
